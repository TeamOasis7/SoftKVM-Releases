SOFT KVM PRIVACY NOTICE
Effective date: July 27, 2026

Soft KVM does not require an account and does not include advertising,
analytics, telemetry, or a central service that collects usage statistics.

1. Local data

Soft KVM stores settings, pairing identity, and trusted peer information on the
Windows PC where it runs. This local data is used to operate the application and
is not sent to SoftKVM.

2. Local network communication

Soft KVM discovers and communicates with another Soft KVM installation on the
local network. Connection discovery, pairing, and encrypted keyboard and mouse
traffic are sent between the PCs selected by the user. SoftKVM does not operate
a relay server for this traffic.

3. Internet communication

When the user checks for updates, Soft KVM contacts the public GitHub API and
GitHub release download service. When the user opens or refreshes the online
manual, Soft KVM requests the manual from GitHub. These services may receive
standard network information such as an IP address under their own privacy
policies. Soft KVM does not add a user identifier or usage-statistics payload to
these requests.

4. Business inquiries and feedback

Information voluntarily sent to teamoasis78@gmail.com is used to respond to the
inquiry, evaluate a report or request, and maintain necessary business records.
Do not send passwords, private keys, pairing secrets, or other unnecessary
sensitive information.

5. Changes and contact

This notice will be updated before Soft KVM adds account, activation, telemetry,
or other central data collection. Privacy questions may be sent to:

teamoasis78@gmail.com
