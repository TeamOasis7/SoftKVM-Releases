# Soft KVM

[English](README.md) | [한국어](README.ko.md) | **日本語**

Soft KVMは、同じ信頼できるローカルネットワーク上の2台のWindows PCを、1組のキーボードとマウスで操作するWindows向けソフトウェアKVMです。ハードウェアKVMスイッチのソフトウェア代替として、アカウント、クラウドサービス、リレーサーバー、追加のハードウェアは必要ありません。

## Soft KVMをダウンロード

- [公式ダウンロードページ](https://teamoasis7.github.io/SoftKVM-Releases/)
- [最新のWindowsリリース](https://github.com/TeamOasis7/SoftKVM-Releases/releases/latest)

両方のPCで最新の公式Soft KVMリリースを使用してください。

## 主な機能

- 2台のWindows PCで1組のキーボードとマウスを共有します。
- 同時操作と画面端を使うSwap modeに対応します。
- 信頼できるローカルネットワーク上で暗号化されたペアリング接続を使用します。
- ローカルのキーボード・マウスブロック、ゲーム精密モード、UAC画面の操作を任意で利用できます。

## クイックスタート

1. 操作されるPCで**Wait**を選び、2桁のコードを確認します。
2. 操作するPCで**Control**を選び、そのコードを入力します。
3. **Start**を選んで接続します。
4. 初回接続では両方のPCの6桁のペアリングコードを比較し、一致した場合だけ両方で**Yes**を選びます。
5. 終了するときは**Stop**を選びます。

## セキュリティとサポート

Soft KVMは信頼できるローカルネットワークでの使用を想定しています。2桁の接続コードと接続グループは対象PCを見つけるためのものであり、パスワードではありません。Soft KVMの検出ポートや待受ポートをインターネットに直接公開しないでください。

インストール手順、リリースノート、ライセンス、プライバシー情報、完全なユーザーガイドは[公式ダウンロードページ](https://teamoasis7.github.io/SoftKVM-Releases/)で確認できます。
