# Soft KVM

[English](README.md) | [한국어](README.ko.md) | **日本語**

Soft KVMは、同じ信頼できるローカルネットワーク上の2台のWindows PCを、1組のキーボードとマウスで操作するWindowsソフトウェアKVMです。アカウント、クラウドサービス、中継サーバー、ハードウェアKVMスイッチは必要ありません。アプリのUIは英語で表示されるため、この説明では実際の英語ボタン名を使用します。

公式ダウンロードページ: https://teamoasis7.github.io/SoftKVM-Releases/ja/

最新の公開リリース: https://github.com/TeamOasis7/SoftKVM-Releases/releases/latest

このREADMEはSoft KVMの最新バージョンを基準にしています。両方のPCで最新の公式リリースを使用してください。

ウェブサイトのソースは [website/ja/index.html](website/ja/index.html) にあります。

## クイックスタート

1. 操作されるPCで **Wait** を選び、表示された2桁のコードを確認します。
2. 操作するPCで **Control** を選び、そのコードを入力します。
3. **Start** を選んで接続します。
4. 初回接続では、両方のPCに表示された6桁のペアリングコードが完全に一致することを確認し、一致する場合だけ両方で **Yes** を選びます。
5. 接続を終了する時は **Stop** を選びます。

接続前に取り消すには、コード入力欄の横にある `×` を選びます。接続を保ったまま入力転送だけを一時停止するには **Pause** を使用します。

## コマンドウィンドウ

`K` または `M` を押した後、250ミリ秒以内にもう一方のキーも押します。コマンドウィンドウが開くまで両方を約0.5秒保持してからキーを離し、次のコマンドキーを押します。

- `X`: ローカルクリックのブロックを切り替える
- `K`: ローカルキーボード入力のブロックを切り替える
- `G`: Game precision modeを切り替える
- `Z`: リモート入力を一時停止または再開する
- `E`: 直ちに停止して入力状態を復旧する
- `Esc`: コマンドウィンドウを閉じる

`X` と `K` は、**Swap mode** がオフの同時制御時だけ使用できます。`K` には **Keyboard control**、`G` には **Mouse control** が有効であることも必要です。

コマンドウィンドウが閉じている通常時の `Esc` は、現在の入力設定、Pause状態、Swapの制御位置に従って通常のキーとして扱われます。**Auto close** を有効にすると、選択した時間が経過した後にコマンドウィンドウが自動で閉じます。

## Settings

- **Start with Windows**: Windowsへのサインイン後にSoft KVMを自動起動し、通知領域に隠します。
- **Minimize while waiting**: 接続後にWait PCのウィンドウを隠します。
- **Keyboard control**: キーボード入力をWait PCへ送ります。
- **Mouse control**: マウス入力をWait PCへ送ります。
- **Block local key**: キーをリモートへ送りながら、Control PCでのローカル入力を防ぎます。
- **Block local clicks**: クリックをリモートへ送りながら、Control PCでのローカルクリックを防ぎます。
- **Game precision mode**: ゲームや3Dアプリ向けのRaw Inputマウス移動量を使用します。
- **Connection group**: 同じグループ名を使用するPCだけを検出します。
- **Pairing**: 現在の接続グループに登録されたPCを表示します。**Unpair** を選ぶと登録を削除し、次回接続時に初回ペアリングをやり直します。
- **Monitor**: 入力とSwap edgeの基準にするモニターを選びます。
- **Control UAC screens**: 管理者の承認後、UAC画面と管理者権限のアプリを操作できるようにします。
- **Block macro / automated input**: マクロや自動化ツールが生成した入力を転送対象から除外します。信頼できる自動化入力を意図的に転送する場合だけオフにしてください。
- **Indicator over**: Controlウィンドウの紫色Swapまたは緑色同時操作ストリップを、独立してドラッグできる常時最前面インジケーターとして分離します。結合中のストリップをダブルクリックすると分離し、分離中のストリップをダブルクリックするとControlウィンドウを復元して再結合します。Wait PCのミニモードは独立して維持されます。

設定は現在のWindowsユーザーごとに保存され、もう一方のPCへ自動でコピーされません。

## Simultaneous control（同時制御モード）

**Swap mode** がオフの場合、接続中のキーボードとマウス入力は、**Keyboard control** と **Mouse control** の設定に従ってWait PCへ送られます。必要に応じてローカル入力ブロックを有効にしてください。

## Swap mode

両方のPCで **Swap mode** をオンにし、同じ **Control direction** を選びます。**Swap time** は0.5秒、1秒（初期値）、1.5秒、2秒から選択でき、Control PCで選んだ時間が進入と復帰の両方に適用されます。

方向は常にControl PCを基準にします。たとえば `Left` の場合、Control PCの左端でポインターを設定時間保持すると、操作がWait PCへ移ります。戻る時は復帰側の端から一度離れ、もう一度その端で設定時間保持します。

両方のPCで方向が異なる場合、または片方だけでSwap modeが有効な場合は、Soft KVMが設定の修正を案内します。

## Game precision mode

**Game precision mode** はControl PC側だけで設定し、Wait PC側と値を合わせる必要はありません。Swap modeでは、ONはRaw Inputの移動量、OFFは通常の低レベルマウスフックの移動量を使用し、スワップ遷移ロジックは変わりません。Swap modeをオフにした同時制御では、この設定をオフにすると通常の絶対ポインター転送に戻ります。

両方のPCで同じ最新のSoft KVM EXEを使用してください。アンチチート機能によってWindowsの合成入力を拒否するゲームはサポートされません。

## 更新と接続

- Settingsの **Check for updates** から最新の公開リリースを確認できます。
- 更新はSHA-256と承認済みSoft KVM発行元の署名が両方とも有効な場合だけインストールされます。
- 現在の発行元を検証できない非常に古いビルドでは、EXEを一度手動で置き換える必要があります。最新の公式リリースから最新のEXE、`SoftKVM-Publisher.cer`、`Install-SoftKVM-Certificate.cmd`を同じフォルダーへダウンロードし、初回起動時の信頼設定を承認してください。
- Windows Defender Firewallの確認が表示されたら、Soft KVMのローカルネットワーク通信を許可します。生成される規則はPrivate/Publicの両プロファイルでローカルサブネットだけを許可します。
- 両方のPCを同じ信頼できるローカルネットワークへ接続してください。
- 接続に失敗した場合は、両方のPCでバージョン、Connection group、Swap modeの設定を確認してください。
- ペアリング画面では両方のPCに表示された6桁すべてを比較し、予期しない接続や一致しないコードを拒否してください。
- 停止、一時停止、切断、緊急復旧を実行すると、転送中のキーとマウスボタンが解放されます。

## 接続のセキュリティ

各PCは保存済みのRSAデバイス識別鍵で、一時P-256 ECDH公開鍵、役割、プロトコルバージョン、nonce、デバイス証明書を含むハンドシェイクに署名します。両者は認証済みのECDH共有秘密から方向別のAES-256-GCMキーを生成します。初回接続時は両方の画面に表示される6桁のコードで相互確認し、その後の接続では保存済みのペアリング相手を確認します。

2桁の接続コードと **Connection group** はPCを検出するための情報であり、パスワードではありません。信頼できるローカルネットワークでのみ使用し、Soft KVMの検出ポートや待受ポートをインターネットへ直接公開しないでください。
