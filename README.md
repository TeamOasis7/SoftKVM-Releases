# Soft KVM

**English** | [한국어](README.ko.md) | [日本語](README.ja.md)

Soft KVM is a Windows software KVM for controlling two Windows PCs with one keyboard and mouse on the same trusted local network. It is a software alternative to a hardware KVM switch: no account, cloud service, relay server, or extra hardware is required.

## Download Soft KVM

- [Official download page](https://teamoasis7.github.io/SoftKVM-Releases/)
- [Latest Windows release](https://github.com/TeamOasis7/SoftKVM-Releases/releases/latest)

Use the latest official Soft KVM release on both PCs.

## What it does

- Shares one keyboard and mouse between two Windows PCs.
- Supports simultaneous control or edge-based Swap mode.
- Uses encrypted, paired connections on your trusted local network.
- Includes optional local keyboard and mouse blocking, game precision mode, and UAC-screen control.

## Quick start

1. On the PC you want to control, select **Wait** and note the 2-digit code.
2. On the controlling PC, select **Control** and enter that code.
3. Select **Start** to connect.
4. On the first connection, compare the 6-digit pairing code on both PCs. Select **Yes** on both PCs only when the codes match.
5. Select **Stop** when you want to disconnect.

## Security and support

Soft KVM is designed for a trusted local network. The 2-digit connection code and connection group help locate the intended PC; they are not passwords. Do not expose Soft KVM discovery or listening ports directly to the internet.
