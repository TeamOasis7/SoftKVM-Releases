THREE CHECKS. ONE SECURE CONNECTION.

Three Security Gates.

Three checks before input control. No cloud relay. Only approved PCs continue to a local, authenticated encrypted channel.

  1. 01 Connection group

    Discover only the intended group

    Soft KVM searches only for PCs using the same connection group on the local network.

  2. 02 Rotating code

    Verify every connection

    The two-digit code shown on the Wait PC must match before the connection can continue.

  3. 03 Verified pairing

    Both PCs approve

    On first connection, confirm the same six-digit code and approve the pairing on both PCs.

COMPARE

A software KVM for local Windows desks.

Soft KVM is built for people who want one keyboard and mouse across two nearby Windows PCs without a hardware switch, remote desktop session, cloud relay, or account.

01

Compared with a hardware KVM

No USB or HDMI switching box is required. Both PCs stay on the network and Soft KVM moves only keyboard and mouse input.

02

Compared with Remote Desktop

Soft KVM does not stream the screen or log in to a remote session. You keep using each PC's own monitor.

03

Compared with Synergy or Barrier

Soft KVM focuses on two Windows PCs, local-subnet discovery, verified pairing, encrypted input, and a compact WinForms interface.

04

Compared with Mouse Without Borders

Soft KVM is designed around direct role selection, explicit pairing confirmation, and no account or cloud service requirement.

COMPATIBILITY

Works on Windows 10/11 x64 over a trusted local network.

Soft KVM is focused on direct control between two Windows PCs on a trusted local network.

01

Same local network

Both PCs must be connected to the same trusted LAN. Internet relay and port forwarding are not supported.

02

Windows x64 on both PCs

Use Windows 10 or 11 x64 and the same Soft KVM version on both computers.

03

Firewall and reconnection

Allow Windows Defender Firewall access for the local network. After a disconnect, the waiting PC stays in Wait with a new code. Return the controlling PC to Control and reconnect with that code.

04

Anti-cheat restrictions

Games that block synthetic Windows input through anti-cheat are not supported.

05

UAC requires elevation

Enable Control UAC screens on the Wait PC and approve the Windows elevation prompt.

FAQ

Before you download.

Can I control a PC over the internet?

Soft KVM is designed for trusted local networks. Do not expose its ports through your router.

Do I need to install .NET?

No. The public Windows x64 build is self-contained.

Does it work with games?

Game precision mode supports many games and 3D apps. Games that block Windows synthetic input through anti-cheat are not supported.

Why can Windows SmartScreen appear?

Soft KVM currently uses a private publisher certificate, not a paid public code-signing certificate. Check the official release source before running it.

Can I share one mouse and keyboard between two Windows PCs?

Yes. Soft KVM is built for keyboard and mouse sharing between two Windows 10/11 x64 PCs on the same trusted local network.

Is Soft KVM a Synergy or Barrier alternative for Windows?

It is a practical alternative for controlling two Windows PCs over a local network with verified pairing and no cloud account.

Does Soft KVM need the internet or a cloud relay?

No. Discovery and input transfer are designed for the local network. Internet relay, account sign-in, and port forwarding are not required.
