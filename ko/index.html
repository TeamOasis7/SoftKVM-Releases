책상 하나, WINDOWS PC 두 대

키보드와 마우스 하나로 Windows PC 두 대를 제어하세요.

Soft KVM은 같은 로컬 네트워크에서 Windows PC 두 대 사이의 키보드와 마우스 입력을 전환하는 소프트웨어 KVM입니다. 계정, 클라우드 서비스, 추가 장비가 필요하지 않습니다.

    양쪽 PC의 페어링 코드를 확인하고 연결을 승인합니다.

비교

로컬 Windows 책상을 위한 소프트웨어 KVM.

Soft KVM은 하드웨어 스위치, 원격 데스크톱 세션, 클라우드 중계, 계정 없이 가까운 Windows PC 두 대를 키보드와 마우스 하나로 쓰려는 사람을 위한 도구입니다.

01

하드웨어 KVM과 비교

USB나 HDMI 전환 장비가 필요하지 않습니다. 두 PC는 네트워크에 그대로 있고 Soft KVM은 키보드와 마우스 입력만 이동합니다.

02

원격 데스크톱과 비교

Soft KVM은 화면을 스트리밍하거나 원격 세션에 로그인하지 않습니다. 각 PC의 실제 모니터를 그대로 사용합니다.

03

Synergy 또는 Barrier와 비교

Soft KVM은 Windows PC 두 대, 로컬 서브넷 검색, 검증된 페어링, 암호화 입력, 작은 WinForms 인터페이스에 집중합니다.

04

Mouse Without Borders와 비교

Soft KVM은 직접적인 역할 선택, 명시적 페어링 확인, 계정과 클라우드 서비스가 필요 없는 사용 방식을 중심으로 설계했습니다.

호환성 및 알려진 제한

신뢰할 수 있는 로컬 네트워크의 Windows 10/11 x64에서 동작합니다.

Soft KVM은 신뢰할 수 있는 로컬 네트워크에서 Windows PC 두 대를 직접 제어하는 용도에 맞춰져 있습니다.

01

같은 로컬 네트워크

두 PC가 같은 신뢰할 수 있는 LAN에 연결되어 있어야 합니다. 인터넷 중계와 포트 포워딩은 지원하지 않습니다.

02

Windows 10/11 x64

Windows 10 또는 11 x64와 동일한 Soft KVM 버전을 두 컴퓨터에서 사용하세요.

03

방화벽 및 재연결

Windows Defender 방화벽의 로컬 네트워크 접근을 허용하세요. 연결이 끊기면 대기 PC는 새 코드로 Wait 상태를 유지합니다. 제어 PC에서 Control을 선택하고 그 코드로 다시 연결하세요.

04

안티치트 제한

Windows 합성 입력을 차단하는 안티치트 게임은 지원하지 않습니다.

05

UAC에는 권한 상승 필요

Wait PC에서 UAC 화면 제어를 켜고 Windows 권한 상승 요청을 승인해야 합니다.

자주 묻는 질문

다운로드 전 확인하세요.

인터넷을 거쳐 제어할 수 있나요?

Soft KVM은 신뢰할 수 있는 로컬 네트워크용입니다. 라우터를 통해 포트를 외부에 노출하지 마십시오.

.NET을 별도로 설치해야 하나요?

아니요. 공개 Windows x64 빌드는 필요한 런타임을 포함합니다.

게임에서도 사용할 수 있나요?

Game precision mode로 여러 게임과 3D 앱을 지원합니다. Windows 합성 입력을 차단하는 안티치트 게임은 지원하지 않습니다.

Windows SmartScreen이 왜 표시될 수 있나요?

현재 Soft KVM은 유료 공인 코드서명 인증서가 아닌 개인 게시자 인증서를 사용합니다. 실행 전 공식 릴리즈 출처를 확인하십시오.

Windows PC 두 대를 마우스와 키보드 하나로 쓸 수 있나요?

예. Soft KVM은 같은 신뢰할 수 있는 로컬 네트워크의 Windows 10/11 x64 PC 두 대 사이에서 키보드와 마우스를 공유하도록 만들었습니다.

Soft KVM은 Windows용 Synergy 또는 Barrier 대안인가요?

Windows PC 두 대를 로컬 네트워크에서 직접 제어하고, 검증된 페어링과 클라우드 계정 없는 연결이 필요하다면 좋은 대안이 될 수 있습니다.

Soft KVM에 인터넷이나 클라우드 중계가 필요한가요?

아니요. 검색과 입력 전송은 로컬 네트워크용으로 설계했습니다. 인터넷 중계, 계정 로그인, 포트 포워딩이 필요하지 않습니다.
