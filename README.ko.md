# Soft KVM

[English](README.md) | **한국어** | [日本語](README.ja.md)

Soft KVM은 같은 신뢰할 수 있는 로컬 네트워크의 Windows PC 두 대를 키보드와 마우스 하나로 제어하는 Windows 소프트웨어 KVM입니다. 하드웨어 KVM 스위치의 소프트웨어 대안으로서 계정, 클라우드 서비스, 중계 서버, 추가 장비가 필요하지 않습니다.

## Soft KVM 다운로드

- [공식 다운로드 페이지](https://teamoasis7.github.io/SoftKVM-Releases/)
- [최신 Windows 릴리즈](https://github.com/TeamOasis7/SoftKVM-Releases/releases/latest)

두 PC 모두에서 최신 공식 Soft KVM 릴리즈를 사용하세요.

## 주요 기능

- Windows PC 두 대에서 키보드와 마우스 하나를 공유합니다.
- 동시 제어와 화면 가장자리 기반 Swap mode를 지원합니다.
- 신뢰할 수 있는 로컬 네트워크에서 암호화되고 페어링된 연결을 사용합니다.
- 로컬 키보드·마우스 차단, 게임 정밀 모드, UAC 화면 제어를 선택적으로 제공합니다.

## 빠른 시작

1. 제어받을 PC에서 **Wait**를 누르고 2자리 코드를 확인합니다.
2. 제어할 PC에서 **Control**을 누르고 해당 코드를 입력합니다.
3. **Start**를 눌러 연결합니다.
4. 최초 연결에서는 양쪽 PC의 6자리 페어링 코드가 같은지 확인하고, 일치할 때만 양쪽에서 **Yes**를 누릅니다.
5. 사용을 마치면 **Stop**을 누릅니다.

## 보안 및 지원

Soft KVM은 신뢰할 수 있는 로컬 네트워크에서 사용하도록 설계되었습니다. 2자리 연결 코드와 연결 그룹은 대상 PC를 찾는 용도이며 비밀번호가 아닙니다. Soft KVM의 검색 또는 수신 포트를 인터넷에 직접 노출하지 마세요.

설치 방법, 릴리즈 노트, 라이선스, 개인정보 처리, 전체 사용 설명서는 [공식 다운로드 페이지](https://teamoasis7.github.io/SoftKVM-Releases/)에서 확인할 수 있습니다.
