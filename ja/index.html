キーボードとマウス1組で、2台のWindows PCを操作。

3つの確認。1つの安全な接続。

3つのセキュリティゲート。

入力制御を始める前に3段階で確認します。クラウドリレーを使わず、承認されたPCだけをローカルの相互認証済み暗号化チャネルで接続します。

  1. 01 接続グループ

    同じグループだけを検出

    ローカルネットワーク上で、同じ接続グループを使用するPCだけを検出します。

  2. 02 接続コード

    接続ごとにコードを確認

    Wait PCに表示される2桁の接続コードが一致した場合のみ次へ進みます。

  3. 03 検証済みペアリング

    両方のPCで承認

    初回接続時に同じ6桁のコードを確認し、両方のPCでペアリングを承認します。

実際のアプリ

クラウドアカウントなしでキーボードとマウスを共有。

小さなバーから Wait と Control をすぐ選べます。ペアリング、入力、Swap mode、起動オプションが必要な時だけ Settings を開きます。

01
画面を占有しない準備状態

Settings を開くか接続を開始するまで、メインウィンドウは小さく保たれます。

クイックセットアップ

数分で、ローカルのWindows PCの操作を始められます。

2台のPCで同じリリースファイルを使います。一方を待機側、もう一方を操作側にします。

  1. 1
    リリースをダウンロード

    一式ZIPをダウンロードするか、EXE、証明書、セットアップCMDを同じフォルダーに置きます。

  2. 2
    信頼設定を一度だけ完了

    初回起動後、Soft KVMの信頼設定プロンプトを承認します。

  3. 3
    各PCの役割を選択

    リモートPCでは Wait、メインPCでは Control を選択します。

  4. 4
    確認して接続

    両方のPCに表示されるペアリングコードを確認して、接続を承認します。

セキュリティ

相互確認で保護された、暗号化されたキーボードとマウス入力。

通信を取得されても入力内容を読み取りにくくし、改ざんまたは再送されたメッセージは拒否されるよう設計しています。

01 CONTROL PC
PAIR ECDH AES-256-GCM VERIFY
02 WAIT PC
A

確認付きペアリング

初回操作の前に、両方のPCで同じペアリングコードを確認して承認します。

B

入力を暗号化

キーボードとマウスの入力は、相互認証されたP-256 ECDH/AES-256-GCMチャネルで送信されます。

C

検証済みアップデート

アップデートはSHA-256と固定された発行者署名の検証を通過した場合のみインストールされます。

D

ローカルサブネット境界

生成されるファイアウォール規則は、Windows LocalSubnet範囲からの接続だけを許可します。

信頼できるローカルネットワーク向け

Soft KVMの検出ポートや待ち受けポートをインターネットに直接公開しないでください。

比較

ローカルのWindows環境向けソフトウェアKVM。

Soft KVMは、ハードウェアスイッチ、リモートデスクトップセッション、クラウド中継、アカウントなしで、近くにある2台のWindows PCをキーボードとマウス1組で使いたい人のためのツールです。

01

ハードウェアKVMとの比較

USBやHDMIの切替器は不要です。2台のPCはネットワーク上に残したまま、Soft KVMはキーボードとマウス入力だけを移動します。

02

リモートデスクトップとの比較

Soft KVMは画面をストリーミングしたり、リモートセッションにログインしたりしません。それぞれのPCの実際のモニターを使い続けます。

03

Synergy / Barrierとの比較

Soft KVMは、2台のWindows PC、ローカルサブネット検出、確認付きペアリング、暗号化入力、小さなWinForms UIに重点を置いています。

04

Mouse Without Bordersとの比較

Soft KVMは、明確な役割選択、明示的なペアリング確認、アカウントやクラウドサービスを必要としない利用を前提に設計しています。

互換性

信頼できるローカルネットワーク上のWindows 10/11 x64で動作します。

Soft KVMは、信頼できるローカルネットワーク上で2台のWindows PCを直接操作する用途に合わせています。

01

同じローカルネットワーク

2台のPCは同じ信頼できるLANに接続されている必要があります。インターネット中継やポートフォワーディングは不要です。

02

Windows 10/11 x64

両方のPCでWindows 10または11 x64と同じSoft KVMバージョンを使用してください。

03

ファイアウォールと再接続

Windows Defenderファイアウォールでローカルネットワークアクセスを許可してください。切断後、Wait PCは新しいコードで待機を続けます。Control PCでControlを選び、そのコードを使って再接続します。

04

アンチチートの制限

Windowsの合成入力をブロックするアンチチート採用ゲームはサポートしていません。

05

UACには昇格が必要

Wait PCでUAC画面の操作を有効にし、Windowsの昇格プロンプトを承認してください。

よくある質問

ダウンロード前に確認してください。

インターネット越しにPCを操作できますか？

Soft KVMは信頼できるローカルネットワーク向けです。ルーター越しにポートを外部公開しないでください。

.NETを別途インストールする必要がありますか？

いいえ。公開Windows x64ビルドには必要なランタイムが含まれています。

ゲームでも使えますか？

Game precision modeで多くのゲームや3Dアプリに対応します。Windowsの合成入力をブロックするアンチチート採用ゲームはサポートしていません。

Windows SmartScreenが表示されるのはなぜですか？

現在のSoft KVMは、有料の公的コード署名証明書ではなくプライベート発行者証明書を使用しています。実行前に公式リリース元を確認してください。

2台のWindows PCでマウスとキーボードを共有できますか？

はい。Soft KVMは、同じ信頼できるローカルネットワーク上の2台のWindows 10/11 x64 PC間でキーボードとマウスを共有するために作られています。

Soft KVMはWindows向けSynergyやBarrierの代替になりますか？

ローカルネットワーク上で2台のWindows PCを操作し、確認済みのペアリングとクラウドアカウントなしの接続が必要な場合に、実用的な代替になります。

Soft KVMにインターネットやクラウド中継は必要ですか？

いいえ。検出と入力転送はローカルネットワーク向けに設計されています。インターネット中継、アカウントログイン、ポートフォワーディングは不要です。
